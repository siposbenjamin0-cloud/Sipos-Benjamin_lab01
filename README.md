# Laborator 2 - Python

Acest proiect contine rezolvarea cerintelor pentru Laboratorul 2.

## Cerinta 1
Citirea si afisarea unui sir de numere si a unei matrice introduse de la tastatura.

## Cerinta 2
Citirea si afisarea unui sir de numere dintr-un fisier text.

## Rulare
Pentru executarea aplicatiei este necesar Python 3.

1. Deschideti proiectul in Visual Studio Code.
2. Pentru Cerinta 1, deschideti console_input.py
   si selectati Run Python File in Terminal.
3. Introduceti numerele si dimensiunile matricei.
4. Pentru Cerinta 2, deschideti array_file_input.py
   si selectati Run Python File in Terminal.
5. Introduceti numele fisierului: numere.txt.
6. Fisierul numere.txt trebuie sa fie in acelasi
   folder cu programele Python.

Daca fisierul nu exista, programul afiseaza
un mesaj de eroare.
